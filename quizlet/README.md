# Quizlet 匯入檔

由 `index.html` 的 `DATA` 產生，每張卡片：

- **正面**：漢字（假名）　例：`会う（あう）`
- **背面**：中文釋義／例句日文／例句中譯（三行）

## 匯入步驟

1. Quizlet → 建立學習集 → 「匯入」
2. 貼上檔案全文
3. 分隔符設定（**兩項都要改成自訂**）：
   - 詞彙與定義之間：**自訂 → Tab**（若介面有 Tab 選項直接選 Tab）
   - 卡片之間：**自訂 → `@@`**

> 背面含換行，所以「卡片之間」不能用預設的「換行」，必須改成 `@@`。
